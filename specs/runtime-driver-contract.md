# Runtime driver contract

Status: stub. Drafted in Phase 3 and stable after Phase 3 of the RFC-36 run plan.

This spec covers the workload spec, driver operations, isolation levels, and mount modes.

## Inputs

Findings below are in the private vault repository `tbhb-dev/agent-orchestration-poc.internal` at commit `69dc14c`.

- Use `container run`, not container machines: [RFC-36 run 1, lines 17, 24, and 26](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T1944Z-RFC-36-agent-hypervisor-attach/findings/r1-apple-container.md#L17).
- The daemon adopts running shims itself, keyed by a deterministic label: [RFC-40 run 11, lines 16 and 34](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2052Z-RFC-40-miscellany-spikes/findings/r11-pty-supervision.md#L16).
- Every workload gets `WORKSPACE_DIR` and `CACHE_DIR` from one canonical host path: [RFC-39 run 13, lines 13 and 17](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2052Z-RFC-39-filesystem-spikes/findings/r13-paths-ownership.md#L13).
- On the host and Seatbelt drivers, a session that calls `setsid()` after reparenting to launchd keeps running after every host kill short of a uid or VM boundary. Stopping a workspace never waits on the guest: [RFC-38 run 7, lines 16 and 75](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2052Z-RFC-38-command-and-control-spikes/findings/r7-host-stop.md#L16).
- Seatbelt does not nest, so harness sandboxes are off inside the generated profile: [RFC-40 run 12, macOS tier table](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2052Z-RFC-40-miscellany-spikes/findings/r12-ipc-sandbox-tiers.md) and [RFC-37 run 9](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2010Z-RFC-37-egress-credential-identity-spikes/findings/r9-seatbelt.md).
- Never share a writable gitdir with a guest: [RFC-39 run 5, lines 14, 15, and 17](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2052Z-RFC-39-filesystem-spikes/findings/r5-git-layout.md#L14).
- The guest doesn't see inotify events for host writes, and virtiofs doesn't map uids: [RFC-39 run 3, line 13](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2052Z-RFC-39-filesystem-spikes/findings/r3-managed-directories.md#L13), [RFC-39 run 13, line 14](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2052Z-RFC-39-filesystem-spikes/findings/r13-paths-ownership.md#L14), and [RFC-36 run 1, line 22](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T1944Z-RFC-36-agent-hypervisor-attach/findings/r1-apple-container.md#L22).
- No long `SIGSTOP` pauses, and memory limits come from the high-water mark: [RFC-38 run 10, lines 16, 32, and 51](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T2052Z-RFC-38-command-and-control-spikes/findings/r10-pause-and-clocks.md#L16) and [RFC-36 run 1, lines 18 and 60](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T1944Z-RFC-36-agent-hypervisor-attach/findings/r1-apple-container.md#L18).
- Guest images include `ps`, which Codex needs at start: [RFC-36 run 1, line 58](https://github.com/tbhb-dev/agent-orchestration-poc.internal/blob/69dc14c7a0e864329c4f8a4301e8688b67363fd4/wiki/proposals/2026-10-07T1944Z-RFC-36-agent-hypervisor-attach/findings/r1-apple-container.md#L58).
